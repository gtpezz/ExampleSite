# 🏷️ Промо-слайдер акций (exampleSite)

Адаптивный интерактивный блок спецпредложений и акций, построенный на современном стеке технологий. Проект оптимизирован для быстрой загрузки и корректного отображения на любых устройствах: от мобильных телефонов до широкоформатных мониторов.

## 🚀 Стек технологий

*   **HTML5** — семантическая структура документа.
*   **Tailwind CSS v4** — современный утилитарный CSS-фреймворк для стилизации (сборка через CLI).
*   **Vanilla JavaScript** — легковесный скрипт для управления состоянием слайдера без тяжелых сторонних библиотек.

## 🛠️ Функционал проекта

*   **Динамическое переключение контента:** При клике на навигационные стрелки («Влево» / «Вправо») скрипт автоматически меняет тексты, изображения, бэджи и ссылки на основе массива данных.
*   **Плавная анимация (Fade effect):** Смена промо-предложений происходит через мягкое растворение контента (`transition-opacity`), что улучшает пользовательский опыт (UX).
*   **Полная адаптивность:** Интерфейс перестраивается из вертикального мобильного вида в горизонтальный десктопный формат благодаря встроенным брейкпоинтам Tailwind.
*   **Безопасная архитектура классов:** Скрипт управляет исключительно данными в DOM и не генерирует Tailwind-классы «на лету», что полностью соответствует требованиям компилятора Tailwind v4.

## 📁 Структура проекта

```text
├── dist/
│   └── output.css      # Скомпилированный и оптимизированный CSS-файл
├── src/
│   └── input.css       # Исходный CSS-файл с директивой @import "tailwindcss"
├── index.html          # Главная страница проекта
└── README.md           # Документация проекта
```

## 💻 Локальное развертывание

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости для компиляции стилей:
   ```bash
   npm install
   ```
3. Запустите сборщик Tailwind CSS в режиме отслеживания изменений:
   ```bash
   npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch
   ```
4. Откройте файл `index.html` в браузере.
